# Hyprland diary

I moved from Windows to Hyprland and started writing down the problems I hit. I use [Caelestia](https://github.com/caelestia-dots/caelestia) dots.

SDDM greeter is [pixie-sddm](https://github.com/xCaptaiN09/pixie-sddm) (forked locally as `pixie-caelestia` so it can follow the Caelestia wallpaper and palette). The TURZX smart screen talks USB through [turing-smart-screen-python](https://github.com/mathoudebine/turing-smart-screen-python); the dashboard on top of that is custom.

Maybe this helps someone else. It definitely helped me.

Each note folder also holds copies of the config / scripts that entry talks about.
